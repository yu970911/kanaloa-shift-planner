# ホテルかなろあ シフト自動作成

希望休と予約客室数から、月次のシフト案を自動で作るツールです。
ブラウザだけで動きます（サーバー・ビルド不要、データは端末の localStorage に保存）。

## 使い方

```bash
node serve.js      # http://localhost:8787
```

`index.html` を直接開いても動きますが、ES モジュールを使っているため簡易サーバー経由を推奨します。

## 画面の流れ

| 手順 | やること |
|---|---|
| ① 希望を集める | 提出状況の確認、希望休の取り込み、予約客室数の入力 |
| ② シフトを組む | 条件を満たす配置を探索（進捗は実際の探索結果を表示） |
| ③ 確認して仕上げる | 手直し、申し送りの確認、スプレッドシートへコピー |

## 希望休の集め方

**LINE・メッセージの貼り付け**（主）と **Googleフォームの回答CSV** の両方に対応します。
メッセージは形式を問わず、名前と日にちが入っていれば読み取ります。

| 書き方 | 解釈 |
|---|---|
| `日下 6日12日は休み` | 6日・12日が休み（苗字だけで照合） |
| `10日まで出勤で退社` | 11日〜月末が休み |
| `15日から出勤します` | 1日〜14日が休み |
| `20日以降はお休み` | 20日〜月末が休み |
| `3連休が取りたい` | 日にちは決めず、生成時に3日続けて休みにする |
| `15〜17 有給で` | 15〜17日が特別休暇（特） |
| `どうしても来られません` | 不在・NG（✖） |

読み取れなかった分・同じ苗字が複数いる場合は、勝手に決めずに「確認が必要」として画面に出します。

## 勤務パターン

| 記号 | 就労時間 | 実働 |
|---|---|---|
| A | 8:00〜17:00 | 8h |
| B | 9:00〜18:00 | 8h |
| C | 8:00〜10:00 / 15:30〜21:30 | 8h |
| D | 11:00〜14:00 / 16:00〜21:00 | 8h |
| E | 6:00〜8:00 / 16:00〜22:00 | 8h |
| F | 17:30〜21:30 | 4h |
| G | 10:00〜15:00 | 5h |
| H | 6:00〜10:00 / 11:00〜15:00 | 8h |

## 生成のルール

**必ず守る（ハード制約）**

- 本人が出した希望休（休・特・✖）の日には入れない
- 連勤の上限、月の最低休日数
- 対応できるパターン・担当の仕事だけを割り当てる
- 1人1日1枠まで／休館日は全員休み

**できるだけ守る（コスト最小化）**

- 各枠の必要人数を満たす（予約客室数に連動）
- 出勤日数を一人ひとりの目安に近づける
- 連休の希望を、予約の少ない並びに入れる
- 前日と同じパターンを優先する

ランダムな初期値で何通りも試し、いちばん評価値の低い配置を採用します（既定300回）。

## ファイル構成

```
index.html      画面
styles.css      見た目
js/model.js     勤務パターン・スタッフ名簿・必要人員のルール
js/solver.js    シフト生成と検証
js/importers.js 希望休の読み取り（メッセージ / CSV）・書き出し
js/app.js       画面まわり
build.mjs       1ファイル版を作る
serve.js        ローカル確認用の簡易サーバー
test/           テスト
```

## テスト

```bash
node --test "test/*.test.mjs"
```

```bash
node build.mjs
```
